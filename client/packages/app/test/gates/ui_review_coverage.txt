# Every surface the design review walks: kind|key|area|snapshots.
#   kind       route and settings and space are checked against the router and the settings index
#              (ui_review_coverage_gate_test.dart); surface rows group the rest and are free-form
#   key        the router path, the settings pane id, or a slug for a surface row
#   snapshots  a comma list of surface names, or `exclude: why` (nothing to look at),
#              or `pending: why` (a screen still waiting for its pictures)
# A surface name is a picture's name without its viewport and theme (scripts/lib/ui_review_names.py);
# it also covers every name that continues it with a dash, so `channel` covers `channel-ephemeral`
# unless a longer registered name, like `channel-settings`, claims it.
