# Kenney source clips

These five clips come from Kenney's Interface Sounds pack, https://kenney.nl/assets/interface-sounds, released under CC0 1.0 (http://creativecommons.org/publicdomain/zero/1.0/).
`LICENSE.txt` is the pack's own license file.
They were converted once from the pack's OGG files to 48 kHz mono float WAV, so the build needs only numpy and scipy.
The files are `glass_001`, `maximize_006`, `maximize_008`, `minimize_006` and `minimize_008`, and `../kenney.py` edits them into the shipped cues.
