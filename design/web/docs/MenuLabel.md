# MenuLabel

An uppercase micro section label inside a Menu.

## Usage

```jsx
<Menu>
  <MenuLabel>Sort by</MenuLabel>
  <MenuItem label="Newest first" selected />
  <MenuItem label="Oldest first" />
</Menu>
```

## Rules

- Use it to name a group of related choices, not for every group.
- Pass the label as plain text; the component handles the casing.
