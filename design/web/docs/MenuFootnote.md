# MenuFootnote

A sentence-case caveat under a menu's choices.

## Usage

```jsx
<Menu>
  <MenuItem label="Everyone" selected />
  <MenuItem label="Only me" />
  <MenuFootnote>Applies to new messages only.</MenuFootnote>
</Menu>
```

## Rules

- One short sentence. If it needs more, the choice needs a Dialog.
