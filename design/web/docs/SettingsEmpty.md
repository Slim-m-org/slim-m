# SettingsEmpty

The empty state of a settings list: a section card holding one line of secondary text.

## Width

No breakpoint. It fills the width of its parent like any SettingsSectionCard.

## Usage

```jsx
<SettingsEmpty message="No invites yet." />
```

- One plain sentence, body size, secondary ink. No icon and no action button.
- Use where a roles, bots or invites list has no rows. A whole pane with nothing to show is SettingsNotice.
