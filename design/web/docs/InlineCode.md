# InlineCode

A short code run inside message text. A raised chip, the opposite of the recessed CodeBlock.

## Usage

```jsx
<p>Run <InlineCode>/invite</InlineCode> to create a link.</p>
```

## Rules

- Use it for commands, identifiers and file names inside a sentence.
- Anything longer than a short token belongs in a CodeBlock.
